# Contributing

For a bug report, include your version, region, what happened, and what you
expected. Please check existing issues first. Do not attach player collections,
raw traffic captures, credentials, or private keys to public issues.

For code changes, fork the repository, make a focused branch, and open a pull
request. Explain the behavior change and checks you ran. Follow
[BUILDING.md](docs/BUILDING.md). Changes affecting accounting, capture, or updates
need a regression check that can detect the original failure. Passing synthetic
protocol tests is not evidence that a new message layout was verified in game.

Contributions use GPL-3.0-only, matching the project. Keep third-party notices.
Maintainers decide which changes to merge and publish. Forks do not update the
official application. Release signing credentials remain private.
