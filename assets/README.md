# Assets and catalog

`PetTracker.ico` is the original application icon. Pet portraits and the family
crystal icons are AION 2 artwork, not GPL-licensed project code. The catalog and
the JSON tables under `src/Core` contain game names, identifiers and assembled
source relationships. Their inclusion does not grant rights over third-party
material. Existing attribution and rights limitations remain in
[THIRD-PARTY-NOTICES.txt](../THIRD-PARTY-NOTICES.txt) and [LEGAL.md](../LEGAL.md).

These files are the assets used by the published 0.1.51 application. Npcap is
not included; install it separately for live tracking.
