# Pet Tracker

A lightweight Aion 2 overlay for recent pet soul activity, ranks and progress.
Game portraits are included.

## Download

[Download Pet Tracker for Windows](https://github.com/0Fox2Give/PetTracker/releases/download/updates/PetTracker.Desktop-win-stable-Setup.exe)

Quit an older Pet Tracker through its tray menu, then run the installer.
Keep Aion 2 open if you wish. Saved collections and preferences stay on your PC.
Npcap is required for capture; the app explains how to get it if it is missing.

## Updates

This installer enables automatic update checks. Open **Settings → Updates** to
check, download and restart when convenient. Background downloads are optional.
Older installers need this edition once; future releases arrive through the app.

Pet Tracker is in beta. The Windows installer is not code-signed yet. Download
only from this repository. In-app updates check the publisher signature and the
package contents before installation.

## Help

Use **Settings → Connection & Help** for connection status and diagnostic details.
[Report a problem](https://github.com/0Fox2Give/PetTracker/issues). Avoid posting
account data or raw capture files publicly.

This repository contains release delivery tools and public verification metadata.
Aion 2 names and portraits belong to their respective owners; Pet Tracker is an
independent companion app.
